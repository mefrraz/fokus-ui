# PROMPT: Páginas de Catálogo e Produto - FOKUS

## CONTEXTO
Este prompt expande o website FOKUS com duas novas páginas:
1. **Página de Catálogo** (listagem de cursos)
2. **Página de Produto/Curso** (detalhes individuais)

**IMPORTANTE:** Manter o mesmo Design System da Landing Page:
- Cores: #102A43, #F8F8F8, #111827
- Glassmorphism obrigatório
- Framer Motion para animações
- Soft & Rounded (rounded-3xl)

---

## NAVEGAÇÃO ENTRE PÁGINAS

### Routing (React Router exemplo)
```javascript
import { BrowserRouter, Routes, Route } from 'react-router-dom';

function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<LandingPage />} />
        <Route path="/cursos" element={<CatalogPage />} />
        <Route path="/cursos/:slug" element={<CoursePage />} />
      </Routes>
    </BrowserRouter>
  );
}
```

### Links Internos
```jsx
// No Header
<Link to="/cursos" className="hover:text-[#102A43] transition-colors">
  Cursos
</Link>

// No Card do Catálogo
<Link to={`/cursos/${curso.slug}`}>
  <button>Ver Detalhes →</button>
</Link>
```
